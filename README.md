# Бот-помощник Minecraft-клана

Первая рабочая версия Discord-бота для проектов и координат. Интерфейс бота — на русском, управление — через slash-команды, формы и кнопки.

## Что уже работает

- `/setup` — выбор каналов проектов, мест, журнала и роли руководства;
- `/bot-status` — проверка связи с ботом;
- `/access set`, `/access remove`, `/access list` — доступ к боту по ролям;
- `/project create` — создание проекта через форму со скриншотом при желании;
- `/project list` — список активных проектов;
- кнопки проекта: вступить, выйти, показать координаты, изменить статус;
- роли участников внутри проекта без создания ролей Discord;
- `/place add`, `/place find`, `/place list` — сохранение и поиск координат; в форме добавления можно выбрать скриншот;
- доступ к местам: весь клан, руководство или только автор;
- `/place delete` и `/place restore` — безопасное удаление и восстановление;
- SQLite, журнал важных действий и восстановление кнопок после перезапуска.

## Доступ по ролям

Администратор сервера или участник с правом «Управлять сервером» всегда имеет полный доступ. Для остальных ролей используются три уровня:

- **Запрещено** — команды и кнопки бота не работают;
- **Основные команды** — проекты, места и проверка состояния бота;
- **Администратор бота** — все команды, включая `/setup` и `/access`.

По умолчанию бот закрыт для обычных участников: доступ есть только у владельца сервера и пользователей с правом «Управлять сервером». Настройте роли командой `/access set`. Команда `/access list` показывает действующие правила, а `/access remove` удаляет правило. Если настроено несколько ролей участника, действует самая высокая из настроенных ролей в списке Discord. Роли без правила не дают доступа. Поэтому можно разрешить нужным ролям «Основные команды» или «Администратор бота»; отдельное правило для `@everyone` не требуется.

## Права бота в Discord

При добавлении приложения выберите области `bot` и `applications.commands`.

Достаточные права бота:

- Просматривать каналы;
- Отправлять сообщения;
- Встраивать ссылки;
- Читать историю сообщений;
- Создавать публичные ветки;
- Отправлять сообщения в ветках;
- Управлять ветками — желательно для будущего архивирования завершённых проектов.

Право «Администратор» боту не требуется.

## Локальный запуск на Windows

1. Установите Python 3.11 или новее.
2. Откройте эту папку в VS Code.
3. Создайте виртуальное окружение:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

4. Установите зависимости:

   ```powershell
   py -m pip install -r requirements.txt
   ```

5. Скопируйте `.env.example` в `.env` и вставьте токен только в локальный `.env`.
6. Запустите:

   ```powershell
   py main.py
   ```

Чтобы команды сразу появились на тестовом сервере, укажите его числовой ID в `SYNC_GUILD_ID`. Без этой переменной Discord создаёт глобальные команды, их появление иногда занимает больше времени.

## Настройка Discord-сервера

Подготовьте:

- форум или текстовый канал для проектов;
- текстовый канал для мест;
- закрытый текстовый канал для журнала;
- при желании отдельную роль руководства.

После запуска выполните `/setup` и выберите эти каналы. Если роль руководства не указана, управленческие действия доступны участникам с правом Discord «Управлять сервером».

## Развёртывание на Bothost

1. Поместите код в репозиторий GitHub или GitLab.
2. В Bothost создайте Discord-бота из этого репозитория.
3. Укажите главный файл `main.py`.
4. Добавьте переменные окружения:

   ```text
   DISCORD_BOT_TOKEN=ваш_токен
   DATABASE_PATH=/app/data/clan_bot.db
   ```

5. Не добавляйте `.env` и папку `data` в Git. Они уже внесены в `.gitignore`.
6. После запуска откройте логи Bothost и убедитесь, что появилась строка `Бот запущен`.

Bothost хранит содержимое `/app/data` между обновлениями контейнера, поэтому база не пропадёт при загрузке новой версии кода.

## Безопасность

- Никому не отправляйте токен и не публикуйте файл `.env`.
- Если токен случайно попал в сообщение или Git, сбросьте его в Discord Developer Portal.
- Закройте канал журнала от обычных участников.
- Периодически скачивайте резервную копию `/app/data/clan_bot.db` из Bothost.
